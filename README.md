# Central Therapy Digital Platform

A digital modernisation project for Central Therapy focused on rebuilding its
public website and establishing the technical foundation for long-term digital
growth.

The project combines modern web development, responsive UX, search engine
optimisation, analytics, Microsoft 365 integration, marketing infrastructure,
deployment and ongoing optimisation.

> **Project Status:** Phase 0 — Engagement & Project Foundation

---

## Project Overview

Central Therapy currently operates an established physiotherapy website that
provides information about its services, funding pathways, practitioner and
booking options.

This project will replace the existing website with a modern, responsive and
maintainable digital platform designed to improve user experience, search
visibility, customer engagement and measurable business outcomes.

The platform will be designed mobile-first while providing a high-quality
experience across smartphones, tablets, laptops and desktop devices.

---

## Objectives

The project aims to:

- rebuild the Central Therapy website using a modern web architecture;
- deliver a responsive and accessible user experience;
- improve website performance and maintainability;
- establish strong technical and on-page SEO foundations;
- protect existing SEO value during migration;
- improve customer enquiry and booking journeys;
- support digital marketing and campaign landing pages;
- establish analytics and conversion measurement;
- integrate appropriate workflows with Microsoft 365;
- provide secure and maintainable deployment practices;
- support continued optimisation after launch.

---

## Project Workstreams

The project is organised into the following major workstreams:

1. Website modernisation
2. User experience and responsive design
3. Search engine optimisation
4. Content strategy and migration
5. Analytics and conversion tracking
6. Microsoft 365 integration
7. Digital marketing infrastructure
8. Security and performance
9. Testing and quality assurance

## Planned Technology Direction

The current technical direction includes:

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- component-based UI architecture

### Content

- headless content management

### Business Integration

- Microsoft 365
- Microsoft Graph
- approved Microsoft services where appropriate

### Infrastructure

- managed cloud hosting
- CDN and edge security
- automated deployment
- monitoring and observability

### Data & Analytics

- web analytics
- conversion tracking
- search performance monitoring
- marketing attribution

Final technology selections will be confirmed following requirements and
architecture analysis.
