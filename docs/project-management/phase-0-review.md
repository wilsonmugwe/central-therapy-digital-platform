## 4. Scope Review

The current project scope includes:

- website rebuild;
- responsive UX;
- content management;
- SEO;
- analytics;
- Microsoft 365 integration where required;
- marketing infrastructure;
- testing;
- migration;
- deployment;
- ongoing optimisation planning.

The project explicitly excludes development of a clinical practice-management
system and storage of clinical records within the public website unless
separately assessed and approved.

---

## 5. Known Assumptions

Several planning assumptions remain unvalidated.

Important examples include:

- access to the current website;
- hosting access;
- DNS access;
- existing analytics availability;
- Search Console availability;
- existing SEO performance;
- booking-system capabilities;
- Microsoft 365 environment;
- content quality;
- marketing account access.

These assumptions are expected to be validated during Phase 1.

They do not prevent discovery from commencing.

---

## 6. Known Risks

Initial significant risks include:

- SEO loss during migration;
- account-access delays;
- scope expansion;
- DNS/email disruption;
- handling of sensitive information;
- third-party integration limitations;
- production defects;
- client approval delays.

The risk register has been established and will remain active throughout the
project.

---

## 7. Architecture Status

No final production architecture has been approved during Phase 0.

Potential technologies have been identified, but final technology selections
will follow:

1. discovery;
2. requirements analysis;
3. solution design;
4. architecture assessment.

This prevents premature commitment to technology before requirements are
understood.

---

## 8. Success Measurement Status

Success categories have been defined.

Specific numerical targets remain intentionally unapproved until current-state
baseline data has been collected.

Phase 1 should investigate available:

- analytics;
- Search Console data;
- SEO performance;
- marketing performance;
- enquiry data;
- booking data;
- website performance.

## 11. Phase 1 Priorities

Phase 1 should begin by determining:

1. what the existing website is built with;
2. where the website is hosted;
3. who controls the domain and DNS;
4. current website structure and URLs;
5. existing SEO performance;
6. existing analytics configuration;
7. current booking system;
8. existing enquiry and referral workflows;
9. current content quality;
10. current marketing channels;
11. Microsoft 365 status;
12. Google Workspace migration dependencies;
13. privacy and security considerations;
14. competitor positioning;
15. existing user journeys.
