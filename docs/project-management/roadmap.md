# Central Therapy Digital Platform — Project Roadmap

**Project:** Central Therapy Digital Platform  
**Document Status:** Draft  
**Owner:** Technical Lead

---

## 1. Purpose

This roadmap defines the planned delivery sequence for the Central Therapy
Digital Platform.

Dates will be refined after discovery and requirements analysis.

---

# Phase 0 — Engagement & Project Foundation

## Objectives

Establish project governance, boundaries and delivery structure.

## Activities

- create repository;
- establish Git workflow;
- create project documentation structure;
- define charter;
- define scope;
- identify stakeholders;
- document assumptions;
- establish success metrics;
- identify deliverables;
- create risk register;
- establish roadmap.

- required foundation documents completed;
- major known project boundaries documented;
- initial risks documented;
- project ready for structured discovery.

# Indicative Delivery Window

The initial website modernisation is currently expected to require
approximately 6–10 weeks depending on:

- discovery findings;
- client availability;
- content readiness;
- integration complexity;
- approval turnaround;
- migration requirements.

A committed schedule will be established after sufficient discovery and
requirements analysis.
